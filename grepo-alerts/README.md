# Alertas para Grepolis (grepo-alerts)

Userscript que agrega alertas con sonido para movimientos y temporizadores en Grepolis.

## Instalación

1. Instalá [Tampermonkey](https://www.tampermonkey.net/) en tu navegador.
2. Abrí [grepo-alerts.user.js](grepo-alerts.user.js) — Tampermonkey ofrece instalarlo.
3. Las actualizaciones se aplican solas vía `@updateURL`.

## Uso

- Botón flotante en la pantalla del juego para configurar alertas.
- Toast + alarma sonora al cumplirse un temporizador.
- Botón 🔊❌ en el toast para silenciar la alarma al instante.
