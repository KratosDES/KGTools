# KGTools

Userscripts y herramientas para Grepolis.

## Herramientas

- **[grepo-alerts](grepo-alerts/)** — Alertas para Grepolis: avisos de movimientos y temporizadores con alarma sonora.

## Instalación

Cada herramienta se instala con [Tampermonkey](https://www.tampermonkey.net/). Ver el README de cada herramienta para los pasos.
