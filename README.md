# Tools — KratosDES

Herramientas derivadas del laboratorio de análisis del ecosistema Grepolis.
Cada herramienta es independiente, modular, y enfocada en QoL (calidad de vida) sin automatizar acciones.

## Principios

- **Sin automatización**: ninguna herramienta ejecuta acciones en nombre del usuario
- **100% local**: sin servidores externos, sin telemetría
- **Código abierto**: todo auditable

## Herramientas

| Herramienta | Descripción | Estado |
|-------------|-------------|--------|
| [grepo-alerts](./grepo-alerts/) | Rastreador de movimientos + notificaciones | MVP ✅ |

## Instalación

Cada herramienta tiene su propio `README.md` con instrucciones.
La mayoría son scripts de TamperMonkey instalables directamente.
